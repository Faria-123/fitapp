### Project name: 
FITLOG
### Short description: 
FITLOG is a modern fitness workout planner that helps users explore exercises, create a daily workout plan, save favorite exercises, and track workout progress.The application provides a clean and responsive interface where users can browse workouts, view detailed exercise information, organize their daily plan, and mark completed exercises.


### Technologies used
**Next.js** = React framework for building the application
**React** = Component-based UI development
**Tailwind CSS** = Styling and responsive design
**DaisyUI** = Pre-built UI components
**React Toastify** = To create toast notifications
**JavaScript** = Using for application logic and functionality

### Key Features
Users can browse a collection of exercises with useful information such as:

- Exercise name
- Muscle groups
- Equipment
- Difficulty
- Duration
- Calories burned
- Rating
